# 📘 SQL Notes Repo

Hey there! 👋
Welcome to my **SQL Notes Repository** 🎉

If you’re learning SQL or just want a quick refresher before exams/interviews, this repo is for you 🚀

---

## 📂 What’s Inside?

This repo covers all the basics (and some advanced stuff too):

* 🏗 **SQL Commands** – DDL, DML, DCL, TCL
* 📊 **Data Types** – Numbers, Text, Dates, etc.
* 🔒 **Constraints** – Primary Key, Foreign Key, Unique, Not Null...
* ⚡ **Operators** – `IN`, `NOT IN`, `BETWEEN`, `LIMIT`
* 🔢 **Aggregate Functions** – `COUNT`, `SUM`, `AVG`, `MAX`, `MIN`
* 🧩 **GROUP BY** & `HAVING`
* ✍ **UPDATE** & ❌ **DELETE**
* 🔗 **Cascading Foreign Keys**
* 🤝 **Joins** – Inner, Left, Right, Full
* 🌀 **UNION / UNION ALL**
* 🔍 **Subqueries**
* 👀 **MySQL Views**
* 📝 **Practice Questions** with examples

---

## 🚀 How to Use

1. Open the notes in **Markdown** format.
2. Copy SQL code snippets into your DB editor (MySQL, PostgreSQL, SQLite, etc.).
3. Play around with them & solve the practice questions.
